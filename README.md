## About the application

**[Grocery list]** is a web application that makes it possible to handle grocery lists easy online. Add groceries, delete them, mark them overlined when in basket

## Technologies

Describe the technologies you used and their role in your project.

- HTML – Defines the structure of the grocery list page, including the input field, Add button, error message and list of items.
- CSS – Controls the appearance and layout of the page, including the grocery list, buttons, input field and completed items.
- JavaScript – Adds the functionality. Allows users to add grocery items, mark them as completed, delete items and validate input. Also uses DOM scripting to create and update list elements dynamically.
- localStorage – Saves the grocery list in the browser so the items remain available when the page is refreshed or reopened in the same browser.
